# Smart Task Dashboard
Простой список задач в браузере. Можно добавлять дела, ставить приоритет, фильтровать по статусу и смотреть, сколько уже сделано. Список сам запоминается и не пропадает после обновления страницы.
## Технологии
- HTML
- CSS
- JavaScript
- LocalStorage (встроенная память браузера)
Ничего ставить не нужно: нет Node, нет npm, нет сервера.
## Как запустить
1. Откройте папку `smart-task-dashboard`.
2. Дважды кликните по файлу `index.html`.
3. Страница откроется в браузере.
Готово. Можно сразу писать задачу и нажимать **Добавить**.
## Как это работает — совсем просто
Представь коробку с листочками.
- `index.html` — это коробка и пустые места: поле для текста, кнопки, список.
- `style.css` — это краски: тёмный фон, красивые кнопки, аккуратные карточки.
- `script.js` — это помощник. Он слушает, что ты делаешь:
  - написал задачу и нажал кнопку — помощник кладёт новый листочек в коробку;
  - нажал галочку — листочек помечается как «готово»;
  - нажал фильтр — показывает только нужные листочки;
  - считает, сколько всего дел и сколько уже сделано;
  - после каждого изменения прячет коробку в память браузера (`LocalStorage`), чтобы завтра листочки были на месте.
Три файла. Один открываешь — остальные подключаются сами.
